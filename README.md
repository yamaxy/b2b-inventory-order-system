# B2B Inventory & Order Management System (b2b-inventory-order-system)

B2B（企業間取引）向けの在庫・注文管理システム バックエンドAPIアプリケーションです。

---

## 🛠 技術スタック

| カテゴリ               | 技術 / ツール     |
|:-----------------------|:------------------|
| **言語**               | Java 21           |
| **フレームワーク**     | Spring Boot 4.0.7 |
| **データベース**       | PostgreSQL 16     |
| **DBマイグレーション** | Flyway            |
| **コンテナ環境**       | Docker            |
| **ビルドツール**       | Gradle            |
| **IDE        **        | IntelliJ IDEA     |
